# Detekcja Obiektów: HOG + SVM
Autorzy: Damian Wujkowski, Szymon Newel, Bartosz Malec, Filip Sosnowski

## Cel projektu

Głównym celem projektu jest praktyczna prezentacja i analiza działania algorytmu HOG+SVM. Metoda ta opiera się na rozpoznawaniu charakterystycznych konturów i kształtów obiektów, zamiast analizy ich kolorów czy tekstur.

## Instalacja
Projekt został przygotowany w formacie Jupyter Notebook (.ipynb), co pozwala na interaktywne uruchamianie kodu krok po kroku.
1. Pobierz repozytorium
2. Skorzystaj ze środowiska, w którym można uruchomić Notebook
3. Pierwsza komórka w pliku .ipynb zawiera instrukcje instalacji wszystkich niezbędnych pakietów

## Uruchomienie

Aby poprawnie korzystać z projektu, wykonaj poniższe kroki:

1. Wybór Kernela

Po otwarciu pliku .ipynb, wybierz Kernel w edytorze. Wybierz środowisko Python 3

2. Uruchomienie instalacji

Uruchom pierwszą komórkę kodu, aby zainstalować wymagane do działania projektu zależności.

3. Wykonywanie

Komórki należy uruchamiać po kolei, od góry do dołu. Każda z nich odpowiada za inny etap projektu.
